# 0.4.3 — 2026-10-24

- **Extension text rendering** preserves literal Horizons designations, resolved targets, satellite names, and name queries when they contain Markdown syntax.
- **Maintenance tooling** synchronizes framework skills and protocol guidance, corrects direct-versus-transitive audit attribution, and documents client-specific hosted connection settings.

## Fixed

- **`astronomy_find_events`** selects local solar, global solar, and lunar eclipses by peaks at or after `start`, retaining earlier contacts ([#62](https://github.com/cyanheads/astronomy-mcp-server/issues/62)).
- **`astronomy_get_rise_set`** certifies shallow horizon crossing direction before building cycles, preserving short real intervals and consecutive daily cycles ([#63](https://github.com/cyanheads/astronomy-mcp-server/issues/63)).
- **`night_in_progress`** retains the preceding polar night's bounded twilight when the first cycle begins after `start`, including nights without a sunset ([#64](https://github.com/cyanheads/astronomy-mcp-server/issues/64)).
