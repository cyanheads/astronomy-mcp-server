# 0.4.0 — 2026-09-23

## Added

- **`astronomy_get_sky_position` / `astronomy_list_visible`: `sun_elongation_degrees`** — angular distance from the Sun in degrees [0,180], seen from Earth's center; 0 for the Sun itself. ([#41](https://github.com/cyanheads/astronomy-mcp-server/issues/41))
- **`astronomy_list_visible`'s `visibility_note`** now flags daylight ("daylight, not naked-eye visible"), civil twilight ("civil twilight, sky still bright"), and glare within 15° of the Sun. The Sun is exempt from all three; the Moon and a negative-magnitude Venus are exempt from the daylight/twilight flags but not glare. ([#41](https://github.com/cyanheads/astronomy-mcp-server/issues/41))
- **`astronomy_get_sky_position`'s `star` lookup** resolves Bayer designations with the Greek letter as a symbol or spelled out and the constellation as its genitive or IAU abbreviation — `α CMa`, `Alpha CMa`, and `Alpha Canis Majoris` all resolve to Sirius. A miss now lists all 32 catalog stars in the message and as `data.catalog_stars`. ([#40](https://github.com/cyanheads/astronomy-mcp-server/issues/40))

## Changed

- **BREAKING:** `astronomy_get_moon_phase`'s `phase_angle_degrees` is renamed to `phase_longitude_degrees` — the Moon–Sun ecliptic-longitude difference (0 new, 180 full). Values are unchanged; only the field name changed. `astronomy_get_sky_position` and `astronomy_list_visible` keep their own Sun–body–observer `phase_angle_degrees`, which reads 0 at full moon. **Migration:** read `phase_longitude_degrees` wherever you previously read `astronomy_get_moon_phase`'s `phase_angle_degrees`. ([#35](https://github.com/cyanheads/astronomy-mcp-server/issues/35))
- **`astronomy_get_rise_set`'s twilight pairs** are now documented as dusk plus the *following* morning's dawn — the dawn beside a given rise is a day later than it, not the dawn that preceded it. No behavior change; the field descriptions and tool description now state the pairing explicitly. ([#36](https://github.com/cyanheads/astronomy-mcp-server/issues/36))
