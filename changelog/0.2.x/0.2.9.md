# 0.2.9 — 2026-08-25

## Added

- **Cache hints** — `createApp` declares hour-long `public` hints on `tools/list`, `prompts/list`, `resources/list`, `resources/templates/list`, and `server/discover`; `astronomy://body/{body}` carries its own day-long `public` `cacheHint`. Effective on protocol revision 2026-07-28 only.

## Changed

- **A tool call with an argument key the schema doesn't declare is now rejected by name** instead of accepted and stripped — `@cyanheads/mcp-ts-core` ^0.12.3 applies `.strict()` to every tool's root input, advertising `additionalProperties: false`. `astronomy_get_satellite_passes` applies `.strict()` itself so its `norad_id`/`name` `oneOf` exclusivity survives onto the advertised `inputSchema`.
- **Every tool's advertised `outputSchema` now declares the error envelope.** Success fields become optional, an `error` object is added, and an `anyOf` recovers the original `required` list per branch — a client that validates `structuredContent` without checking `isError` stops rejecting error results as schema mismatches.
