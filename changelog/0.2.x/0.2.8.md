# 0.2.8 — 2026-08-18

## Added

- **`astronomy_get_sky_position`** — returns `body_metadata` (`type`, `mean_radius_km`, `naked_eye`) inline for solar-system bodies, the same values served at `astronomy://body/{body}`, so a client without resource support reaches them without a second call. Absent for a catalog star, which has no card. ([#24](https://github.com/cyanheads/astronomy-mcp-server/issues/24))

## Fixed

- **`astronomy_list_visible`** — `format()`'s per-body scan line now tails every numeric field (altitude, azimuth, RA, Dec, magnitude, angular diameter, phase angle, illuminated fraction, ecliptic lon/lat) with its exact value, matching the `content[]`/`structuredContent` parity every other tool already has; previously only `distance_au` carried a tail. The rounded display figure still leads each value. This grows a full sky sweep's response by roughly 1.5x (10,822 → 16,517 characters on a 39-body sweep). ([#14](https://github.com/cyanheads/astronomy-mcp-server/issues/14))
