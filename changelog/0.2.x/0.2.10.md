# 0.2.10 — 2026-09-19

## Added

- **`.github/workflows/codeql.yml`** — the fleet-standard CodeQL workflow, now shipped in the repo (runs only while GitHub's CodeQL default setup is off).
- **`createApp({ sessionMode: 'stateless' })`** declared in `src/index.ts` — the durable form of the session posture this server already ran under (`.env.example` and the `Dockerfile` set it too); `MCP_SESSION_MODE` still overrides when set.
- **`errors[]` entries carry `thrownBy: 'service'`** on every reason raised below the handler, so the new `error-contract-unthrown` lint rule verifies it without a false miss.

## Changed

- **A schema-rejected tool call (unknown key, wrong type, missing required field) now carries `structuredContent.error`** alongside its `content[]` text — a client that reads only the structured envelope no longer misses an argument-validation rejection.
- **A client-injected metadata key (`_meta`, `tool_call_description`, `toolCallId`, or any undeclared underscore-prefixed key) is dropped before schema validation** instead of triggering the strict-input rejection added in 0.2.9; a declared key or one whose case/separator-folded form names exactly one declared key is unaffected. `inputSchema` is unchanged.
- **Tool error text ends with `(reason <reason> · not retryable)`** when the thrown error carries a `data.reason` or a boolean `data.retryable`, and an argument rejection appends a `Recovery: <hint>` line derived from the schema — dropped when the message already states the hint verbatim.
- **Skill tree moved from `skills/` to `framework-skills/`** — Claude Code and Codex auto-load a plugin's root `skills/`, so shipping `.claude-plugin/`/`.codex-plugin/` handed these development skills to every installing agent. The agent-facing mirrors (`.claude/skills/`, `.agents/skills/`) keep their names.
- **Releases now ship through a release PR** (`CLAUDE.md`/`AGENTS.md` `## Publishing`, mode `straight-through`) — `git-wrapup` lands the commit stack on `release/<version>` and opens the PR; `release-and-publish` fast-forwards `main` and tags from there.
- **README reorganized** around an Overview section and a per-tool capability reference, matching the framework's updated `polish-docs-meta` reference.
