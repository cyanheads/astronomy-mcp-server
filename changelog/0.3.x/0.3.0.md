# 0.3.0 — 2026-09-23

## Added

- **`astronomy_find_events`: `solar_eclipse` without an observer now searches globally**, returning `kind`, `peak_utc`, `obscuration`, and — for a total or annular eclipse — the `peak_latitude_degrees`/`peak_longitude_degrees` where it is greatest.
- **Both eclipse classes report `contact_altitudes_degrees`** — the eclipsed body's altitude at each contact — when an observer is supplied.
- **Every `find_events` search stops at the end of 2100**, the close of the supported span; a result short of the requested `count` carries an enrichment `notice` saying so.

## Changed

- **`local_visible` is now any-contact, not peak-only**, on both eclipse classes — an eclipse visible only near sunrise or sunset used to read as not visible.
- **Lunar eclipses accept an optional observer** for local circumstances; contact times stay geocentric either way.

## Removed

- **`observer_required` is gone.** `solar_eclipse` no longer requires an observer. A lone `latitude` or `longitude` on either eclipse class (not both) now throws `incomplete_observer` instead.

## Fixed

- **`astronomy_stargazing_plan` step 1** named the nonexistent `openstreetmap_geocode`; it now names `openstreetmap_search_places` and `ref_timezone_lookup` (#37).

## Dependencies

- `@types/node` (dev) `^26.6.1` → `^26.6.2`
